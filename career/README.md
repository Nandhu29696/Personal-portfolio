## Tailoring each application

Based on the [Job Bank resume guidance](https://www.jobbank.gc.ca/findajob/resources/write-good-resume):

1. **Read the posting first.** Note the job title, its top three requirements, and the exact wording of key skills.
2. **Resume:** reorder the skills and bullets so the posting's requirements come first, and use the same terms (for example "Azure OpenAI" rather than "LLM APIs" if that's what they wrote). Keep it to two pages.
3. **Cover letter:** replace every yellow `[placeholder]` and remove the highlighting. Name one specific requirement from the posting in the third paragraph and connect it to a project.
4. **Keep it factual.** Only claim what you can explain in an interview.
5. **Proofread twice**, then ask someone else to read it.
6. **Send PDFs** unless the employer asks for Word: in Word, File → Save As → PDF.
